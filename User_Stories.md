# User Stories: The "Jobs-to-be-Done" Map

> [!NOTE]
> This map represents the core personas and their primary goals structured as an interconnected journey.

| 🎓 Student | 💼 Placement Officer | 🏢 Recruiter |
| :--- | :--- | :--- |
| **🪄 Auto-Profile**<br><br>As a Student, I want to auto-fill my profile from my resume, so that I can apply to jobs in one click. | **📊 Dashboard**<br><br>As a Placement Officer, I want a real-time analytics dashboard, so that I can report placement stats to the Dean instantly. | **✨ AI Funnel**<br><br>As a Recruiter, I want AI-driven candidate shortlisting, so that I can find the best-fit candidates in minutes. |
| **🔔 Instant Alerts**<br><br>As a Student, I want instant match alerts, so that I never miss an ideal opportunity. | **📨 Bulk Automation**<br><br>As a Placement Officer, I want to send bulk automated updates, so that I can reduce manual coordination. | **📅 Virtual Drives**<br><br>As a Recruiter, I want an integrated scheduling tool, so that I can conduct virtual drives seamlessly. |
