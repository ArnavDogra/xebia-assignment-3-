# Interactive Wireframes & User Flow

**Flow:** `[Screen 1: Student Login]` ➡️ `[Screen 2: AI Job Match]` ➡️ `[Screen 3: Command Center]`

## Screen 1: Student - Login/Home
*(Mobile Screen)*
* **Visual Elements:**
  * Clean, deep navy header.
  * Widget: **Your AI Skill Score: 85/100** (Highlighted in electric blue).
  * List: **Upcoming Drives** showing companies and roles.
  * **CTA Button:** A prominent "Apply Now" button for a Software Engineer role.

## Screen 2: AI Job Match
*(Mobile/Tablet Detail Screen)*
* **Visual Elements:**
  * Job Card: "Software Engineer at Fintech Unicorn".
  * **AI Match Badge:** "92%" clearly visible.
  * **Radar Chart / Skill Tags:**
    * ✅ *Matched Skills:* Python, React, Cloud
    * ❌ *Missing Skills:* System Design
  * **Action:** "Auto-Apply with AI" button.

## Screen 3: Placement Officer - Command Center
*(Desktop Dashboard)*
* **Visual Elements:**
  * Top navigation with a red alert badge: "🚨 5 Students missing documents."
  * **Funnel Chart:**
    * Students Registered: 500
    * Shortlisted: 300
    * Interviewed: 200
    * Placed: 180
  * **Side Panel:** "Today's Scheduled Drives" outlining daily logistics.
