# Key User Actions

### Student

1. Login to platform.
2. View AI skill score.
3. Browse recommended jobs.
4. Check AI match percentage.
5. Auto-apply to opportunities.

### Placement Officer

1. Monitor placement statistics.
2. Track missing documents.
3. Manage placement drives.
4. Export reports.
5. Communicate with students.

The wireframes demonstrate the primary user journeys while maintaining a clean, scalable, and responsive interface suitable for students, placement officers, and recruiters.
